> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dedup inbound announces by a per-destination bounded ring (capacity 64) of announce random-blobs (the 10-byte `random_hash`) instead of by `packetHash`, matching RNS — hardening anti-replay and re-broadcasting every fresh announce in relay mode.

**Architecture:** One production file changes: `Sources/ReTiCATransport/Transport.swift`. A new `State.announceBlobs: [Data: RingSet]` field holds each destination's recent blobs (reusing the existing `RingSet`). The `.received` reducer skips the shared `packetHash` dedup for `.announce` packets and instead blob-dedups inside the `.announce` case; a fresh announce updates the path only via the unchanged `shouldReplace` but is re-broadcast (relay mode) regardless. Non-announce packets keep `packetHash` dedup unchanged. Core `Sources/ReTiCA/*` is untouched.

**Tech Stack:** Swift, The Composable Architecture (~1.26), Swift Testing (`@Test`/`#expect`), `TestStore`. Cross-validation fixtures generated by genuine Python-RNS 1.3.8 under the `rns` conda env.

## Grounding facts (verified — do not re-derive)

- `RingSet` (`Sources/ReTiCATransport/RingSet.swift`) is an `Equatable` bounded, insertion-ordered set. `init(capacity: Int = 1000)`. `@discardableResult mutating func insert(_ item: Data) -> Bool` returns `false` if the item is already present, evicts the oldest when over capacity. `func contains(_ item: Data) -> Bool`. This is exactly the blob-ring API.
- `Announce.parse(payload:destinationHash:contextFlagSet:)` returns an optional whose `.randomHash` is the 10-byte `5 random ‖ 5 big-endian time` value. Transport already calls it and reads `parsed.randomHash` (used by `Transport.announceEmitted`).
- RNS keys its announce dedup on `packet.data[KEYSIZE//8 + NAME_HASH_LENGTH//8 : +10]` (`Transport.py:1807`) = that same `random_hash`; the per-destination list is bounded to `MAX_RANDOM_BLOBS = 64` (`Transport.py:98`); the dedup decision is `not random_blob in random_blobs` (`Transport.py:1824`).
- `hashablePart` (`Packet.swift:127`) = `[destType|packetType] ‖ destHash ‖ context ‖ payload`; `payload` includes `random_hash`, so an exact relayed copy shares the original's `packetHash` **and** blob. Signatures are randomised (Ed25519 via CryptoKit), so re-signing the same data yields a different `packetHash` but the **same** blob — this is the anti-replay gap this slice closes.
- Existing `Transport.State`: `localDestinations`, `learned`, `interfaces`, `transportIdentity`, `seenPacketHashes = RingSet()`, `linkTable`. `shouldReplace(_ existing: LearnedDestination?, with candidate: LearnedDestination) -> Bool` — true when candidate emission is newer, or equal emission with fewer hops.
- Test idioms in `Tests/ReTiCATransportTests/TransportTests.swift`: Swift Testing; `TestStore(initialState: Transport.State()) { Transport() }`; `store.exhaustivity = .off`; relay setup via `.interfaceConnected(InterfaceID(...))` ×N then `.setTransportIdentity(id)` with `withDependencies { $0.date = .constant(Date(timeIntervalSince1970: 0)) }`; `store.receive { if case .delegate(.pathLearned) = $0 { return true }; return false }`; `LockIsolated<Data?>` to capture an action payload. To assert **no** further action: after the send, set `store.exhaustivity = .on` so any pending unreceived action fails at cleanup (as in `linkRequestToUnknownDestinationIsNotSurfaced`).
- Cross-val fixtures: generator `Tests/ReTiCATransportTests/Vectors/generate_transport_fixtures.py`; JSON `transport_fixtures.json`; decoder `TransportVectorFixtures.swift` (`.load()` via `Bundle.module`); consumer tests use `Data(hexString:)` and live in `Tests/ReTiCATransportTests/Vectors/*CrossValidationTests.swift`.

```swift
                case .announce:
                    // Don't learn a path to one of our own destinations.
                    guard state.localDestinations[packet.destinationHash] == nil else { return .none }
                    guard let parsed = Announce.parse(payload: packet.payload,
                                                      destinationHash: packet.destinationHash,
                                                      contextFlagSet: packet.contextFlag)
                    else { return .none }
                    // Anti-replay: a previously-seen random-blob for this destination is a replay.
                    // RingSet.insert both tests and records; false → already present → drop.
                    var ring = state.announceBlobs[packet.destinationHash]
                        ?? RingSet(capacity: Transport.announceBlobRingSize)
                    guard ring.insert(parsed.randomHash) else { return .none }
                    state.announceBlobs[packet.destinationHash] = ring

                    let emitted = Transport.announceEmitted(parsed.randomHash)
                    // Path-table next hop: relayed (HEADER_2) → its transport_id; directly heard → the dest.
                    let nextHop = packet.transportId ?? packet.destinationHash
                    let candidate = LearnedDestination(
                        identity: parsed.identity, appData: parsed.appData, ratchet: parsed.ratchet,
                        interfaceID: interfaceID, hops: packet.hops, nextHop: nextHop,
                        announceEmitted: emitted)
                    var effects: [Effect<Action>] = []
                    // Update the path only if this fresh announce improves it (unchanged logic).
                    if Transport.shouldReplace(state.learned[packet.destinationHash], with: candidate) {
                        state.learned[packet.destinationHash] = candidate
                        effects.append(.send(.delegate(.pathLearned(
                            destinationHash: packet.destinationHash, hops: packet.hops))))
                    }
                    // Relay mode: re-broadcast EVERY fresh announce (not just path-improving ones),
                    // subject to the hop limit — same HEADER_2 packet as 4b-1, payload verbatim.
                    if let relayID = state.transportIdentity,
                       Int(packet.hops) + 1 < Int(Packet.maxHops) {
                        let rebroadcast = Packet(
                            headerType: .header2, packetType: .announce, transportType: .transport,
                            destinationType: packet.destinationType, context: packet.context,
                            contextFlag: packet.contextFlag, hops: packet.hops + 1,
                            destinationHash: packet.destinationHash, transportId: relayID.hash,
                            payload: packet.payload)
                        if let rebroadcastRaw = try? rebroadcast.packed() {
                            effects.append(contentsOf: state.interfaces
                                .filter { $0 != interfaceID }
                                .map { Effect<Action>.send(.delegate(.transmit($0, rebroadcastRaw))) })
                        }
                    }
                    return effects.isEmpty ? .none : .merge(effects)
```

@MainActor
private func makeRelayStore(_ relay: Identity) async -> TestStore<Transport.State, Transport.Action> {
    let store = TestStore(initialState: Transport.State()) { Transport() } withDependencies: {
        $0.date = .constant(Date(timeIntervalSince1970: 0))

/// An exact replay of an announce is dropped by blob-dedup: no second path learn AND (in relay
/// mode, where every fresh announce is re-broadcast) no second re-broadcast.
@Test @MainActor func exactReplayAnnounceIsDroppedAndNotRebroadcast() async {
    let id = Identity()
    let (raw, destHash) = makeAnnouncePacket(identity: id, appName: "app", aspects: ["svc"],
                                             hops: 2, emitted: 1000)
    let store = await makeRelayStore(Identity())
    await store.send(.received(InterfaceID("i0"), raw))
    await store.receive(.delegate(.pathLearned(destinationHash: destHash, hops: 2)))
    await store.receive { if case .delegate(.transmit) = $0 { return true }; return false } // first re-broadcast

    await store.send(.received(InterfaceID("i0"), raw))
    store.exhaustivity = .on   // any pending re-broadcast/pathLearned now fails at cleanup

    let f = try TransportVectorFixtures.load()
